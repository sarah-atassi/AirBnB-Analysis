# AirBnB Analysis

# Project Overview:

This project analyzes Airbnb listings in New York City to explore pricing trends, room types, and review activity. Using Python and Pandas, I cleaned and analyzed multiple datasets to identify patterns in listing prices, availability, and customer reviews.

# Tools & Technologies

Python

Pandas

Data visualization

Data cleaning and exploratory data analysis (EDA)

# Objectives

Analyze Airbnb listing prices and room types.

Examine review dates to understand listing activity and demand patterns.

Identify pricing trends and seasonal patterns.

Use data visualizations to communicate findings.

# Key Skills Demonstrated

Data cleaning, data manipulation, exploratory data analysis, trend analysis, and data visualization.
